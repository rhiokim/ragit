# Narrative TUI

Isolated Bun/OpenTUI viewer for versioned sanitized `ragit narrative` models.

## Role Boundary

- Input: `--model <path>` only
- Output: local interactive explorer
- Canonical artifact: **not here**. The canonical narrative artifact is still the HTML report generated by `ragit narrative`.
- Data source: versioned viewer-safe JSON exported by `ragit narrative --emit-model <path>`
- Boundary: no direct `.ragit` reads, no git reads, no root workspace coupling

## Install

```bash
cd /Users/rhio/Works/my/ragit/tools/narrative-tui
bun install
```

## Standard Run Procedure

1. Generate the canonical HTML report and the optional viewer model from the repo root.

```bash
cd /Users/rhio/Works/my/ragit
pnpm ragit narrative --emit-model .ragit/reports/narrative/current.model.json
```

2. Move into the isolated viewer directory and open the model.

```bash
cd /Users/rhio/Works/my/ragit/tools/narrative-tui
bun run start -- --model ../../.ragit/reports/narrative/current.model.json
```

## Local Fixture Run

## Compatibility Rules

- `schemaVersion` is the structural compatibility key.
- `projectionPolicyVersion` is the viewer-safe projection governance key.
- `projectionMode` is currently fixed to `viewer-safe`.
- `producerVersion` is metadata only.
- If `schemaVersion` is missing, the viewer treats the payload as `legacy-unversioned` compatibility input.
- If the model major version or projection policy version is unsupported, the viewer fails fast and prints an explicit error.

## Projection Rules

- The viewer renders only the projected public model. It does not reconstruct hidden fields.
- Binding state appears as counts, not as raw goal/session identifiers.
- `trust` badges identify whether an item came from durable docs, reviewed/promoted artifacts, or operational events.
- `sensitivity` badges identify whether a value is `standard`, `redacted`, or `restricted`.
- `freshness` badges identify whether an item is `fresh`, `suspect`, or `stale` based on the exported drift overlay from `ragit narrative`; the viewer does not recompute drift itself.
- `validation` badges identify whether an item is `verified`, `attention`, or `unverified` based on harness/drift assets; this is current validation posture, not the full verification chronology.
- The TUI right rail follows `Intent | Validation | Timeline`, while the HTML canonical report adds a dedicated Validation Panel.
- `restricted` means the producer intentionally hid raw binding values and exported only a safe summary.

## Failure Handling

- If `bun install` was never run, the viewer will not start.
- If `--model` points to a missing or invalid file, the viewer fails before rendering.
- If the emitted model `schemaVersion` or `projectionPolicyVersion` is unsupported, fix the viewer or regenerate with a compatible producer.
- If the viewer fails after the HTML report was already generated, treat the canonical narrative export as successful and the viewer as an optional local failure.
