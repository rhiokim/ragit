## 무엇을 하는 명령인가

`harness promote`는 reviewed harness artifact를 durable `docs/harness/**` 문서로 변환하고, `HEAD`가 있으면 targeted ingest까지 이어갈 수 있습니다.

## 기본 구문

```bash
pnpm ragit harness promote --input <path|-> [--dry-run] [--format text|json|both] [--cwd <path>]
```

## 핵심 포인트

- `reviewed` 상태의 harness artifact만 승격할 수 있습니다.
- `promote`는 durable docs를 쓰는 명령이며, 실행 엔진이 아닙니다.
- operational evidence가 필요하면 <a href="/ko/docs/commands/harness/run">`harness run`</a>을 사용하십시오.
