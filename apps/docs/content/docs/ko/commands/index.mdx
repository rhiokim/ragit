`commands` 그룹은 개별 명령 상세 문서의 새 진입점입니다.
각 leaf 페이지는 한 개의 실행 가능한 CLI 명령을 사용자 관점과 에이전트 연동 관점에서 함께 설명합니다.

## 여기서 시작하십시오

- 저장소를 처음 설정할 때는 <a href="/ko/docs/commands/init">`init`</a>부터 읽으십시오.
- 커밋 사이에서 snapshot 지식과 결속된 beliefs/open loops가 의미적으로 어떻게 달라졌는지 보고 싶을 때는 <a href="/ko/docs/commands/log">`log`</a>를 읽으십시오.
- 세션, memory, harness, ingest 흐름의 시간축을 읽고 싶을 때는 <a href="/ko/docs/commands/timeline">`timeline`</a>을 읽으십시오.
- 현재 `HEAD` 기준으로 어떤 지식 객체를 다시 검토해야 하는지 보고 싶을 때는 <a href="/ko/docs/commands/drift">`drift`</a>를 읽으십시오.
- 현재 `drift` 결과를 바탕으로 보수적인 복구 계획이나 safe 자동 실행 범위를 계산하려면 <a href="/ko/docs/commands/repair">`repair`</a>를 읽으십시오.
- secret-like content 또는 unsafe remote egress posture가 RAGit 소유 상태로 새어 들어갔는지 점검하려면 <a href="/ko/docs/commands/security/audit">`security audit`</a>를 읽으십시오.
- 인덱싱된 지식에서 바로 검색할 때는 <a href="/ko/docs/commands/query">`query`</a>를 읽으십시오.
- 다음 에이전트 단계에 넣을 압축된 패킷이 필요하면 <a href="/ko/docs/commands/context/pack">`context pack`</a>을 읽으십시오.
- 일반 검색이 아니라 현재 작업을 이어서 복원하려면 <a href="/ko/docs/commands/memory/recall">`memory recall`</a>을 읽으십시오.
- transcript와 tool trace에서 session artifact를 추출하려면 <a href="/ko/docs/commands/session/materialize">`session materialize`</a>를 읽으십시오.
- 저장된 harness suite를 실행하고 deterministic evaluation 결과를 수집하려면 <a href="/ko/docs/commands/harness/run">`harness run`</a>을 읽으십시오.

## 이 문서들을 읽는 방법

- 모든 leaf 페이지는 동일한 섹션 구조를 사용하므로 구문, 옵션, payload 예시, 주의점을 빠르게 찾을 수 있습니다.
- `--input <path|->`를 지원하는 명령은 JSON payload 예시를 포함합니다.
- `--view`를 지원하는 명령은 `minimal`, `default`, `full` 차이를 설명합니다.
- `--dry-run`을 지원하는 명령은 실제 변경 전에 무엇을 검증하는지 설명합니다.

## 빠른 매핑

- `query`: "이 질문에 맞는 인덱싱된 지식은 무엇인가?"
- `log`: "snapshot 이력에서 무엇이 의미적으로 달라졌고, 다음 agent는 무엇을 계속 믿어야 하는가?"
- `timeline`: "session, memory, harness, ingest 흐름에서 실제로 무슨 일이 일어났는가?"
- `drift`: "현재 HEAD 기준으로 무엇이 아직 믿을 만하고, 무엇을 다시 검토해야 하는가?"
- `repair`: "현재 drift 결과를 기준으로 어떤 복구 액션을 계획하거나 안전하게 적용해야 하는가?"
- `security audit`: "raw-looking 민감정보나 unsafe remote egress posture가 RAGit 소유 상태에 남아 있는가?"
- `context pack`: "이 목표를 위해 최소-충분 컨텍스트 패킷은 무엇인가?"
- `memory wrap`: "작업을 멈추기 전에 무엇을 기록해야 하는가?"
- `memory recall`: "작업을 다시 시작하기 전에 무엇을 불러와야 하는가?"
- `memory promote`: "어떤 내용을 지속 가능한 프로젝트 기억으로 승격해야 하는가?"

예전 진입점이 더 익숙하시다면, 기존 <a href="/ko/docs/cli-reference">CLI Reference</a> 페이지는 이제 이 그룹으로 안내하는 호환 페이지 역할만 합니다.
