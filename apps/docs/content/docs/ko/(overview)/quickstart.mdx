이 문서는 전체 onboarding 절차를 다 설명하는 페이지가 아니라, 적절한 시작점을 고르는 허브입니다.
신규 프로젝트에 RAGit을 적용하려면 <a href="/ko/docs/getting-started">Getting Started</a>부터 읽으십시오.
RAGit 저장소 자체를 개발 중이라면 <a href="/ko/docs/init-guide">Init Guide</a>를 읽으십시오.

## 경로 선택

- 신규 프로젝트 적용: <a href="/ko/docs/getting-started">Getting Started</a>
- 저장소 로컬 개발: <a href="/ko/docs/init-guide">Init Guide</a>
- 명령 참조: <a href="/ko/docs/commands">Commands</a>
- memory model과 control-plane 동작: <a href="/ko/docs/memory-model">Memory Model Guide</a>
- Agent CLI JSON 규약: <a href="/ko/docs/agent-cli">Agent CLI Contract</a>

## 문서 사이트 로컬 실행

```bash
pnpm docs:dev
```

브라우저에서 `/en/docs` 또는 `/ko/docs`를 확인합니다.

전체 onboarding이 필요하다면 이 문서를 source of truth로 사용하지 말고 <a href="/ko/docs/getting-started">Getting Started</a>를 사용하십시오.
