## What It Does

`status` prints the current repository state that matters to RAGit: branch, HEAD, backend, manifest count, knowledge readiness, event-ledger activity, the split between the configured embedding profile and the persisted store contract, and the active embedding-cache namespace summary.

## When To Use / When Not To Use

### When to use it

- You want a quick operational snapshot of the current repository.
- You want to confirm whether the store is loaded and whether retrieval should be ready.
- You want to inspect config surfaces without opening files manually.

### When not to use it

- You want a deeper health diagnosis. Use <a href="/en/docs/commands/doctor">`doctor`</a>.
- You want to change config values. Use <a href="/en/docs/commands/config/set">`config set`</a>.

## Syntax

```bash
pnpm ragit status [--format text|json|both] [--cwd <path>]
```

## Arguments And Options

- `--format text|json|both`: Choose human text, JSON, or both.
- `--cwd <path>`: Run against another repository.

## Input And Output Contract

- There is no positional input and no JSON payload input.
- JSON output includes `branch`, `head`, `backend`, `zvec`, `supported_types`, `docsAuthority`, `knowledge`, `events`, `manifests`, `embedding.configured`, `embedding.store`, `embedding.cache`, `embedding.ready`, `embedding.needsMigration`, and `format`.
- `embedding.cache` reports `enabled`, `dir`, `namespaceId`, `entryCount`, `batchPolicy`, `retryPolicy`, `writable`, and `namespaceReadable`.
- Agents should usually call `--format json`.

## Examples

Human terminal flow:

```bash
pnpm ragit status
```

Agent-oriented flow:

```bash
pnpm ragit status --format json
```

## Failures And Cautions

- `status` is a summary, not a repair command.
- A loaded store does not guarantee that your latest docs are indexed. Run <a href="/en/docs/commands/ingest">`ingest`</a> after content changes.
- Event counters reflect append-only operational ledger activity, not snapshot semantic deltas. Use <a href="/en/docs/commands/timeline">`timeline`</a> when you need the detailed time axis.
- When `embedding.needsMigration=true`, change the store with <a href="/en/docs/commands/migrate/embeddings">`migrate embeddings`</a> before running write paths against the new provider contract.
- When `embedding.cache.enabled=false` while cache is expected, inspect <a href="/en/docs/commands/doctor">`doctor`</a> for `embedding.cache-dir` and `embedding.cache-namespace`.
